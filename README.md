# Rainclassroom_Plugin

## 1.2.1：电脑端复选框显示修复

雨课堂电脑端全局样式对输入框设置了 `appearance: none`，导致助手中的原生复选框不显示。此版本在助手内部恢复复选框外观、可见尺寸和键盘焦点提示，覆盖「开启答题」、图片选项及下载列表。答题启用、保存和提交逻辑保持原样。完整替换 `main.js` 后刷新外层页面，标题应显示 **1.2.1**。

已在带有相同全局输入框样式的本地浏览器测试页确认复选框可见、可勾选、保存后显示开启；原有 80 项测试通过。

## 1.2.0：面板自动显示与可选答题

完整更新 `main.js`（包括脚本头部）并刷新外层课堂标签页。**答题默认关闭**，在面板的「答题助手」中配置后点击「保存并应用」。当前支持课堂发布的单选题和多选题；判断题按网站给出的两个选项处理。

- 每个浏览器标签页只有顶层一个面板，普通入口页、新页面和 SPA 路由均可自动显示，不再等下载接口触发；登录界面仍自动隐藏。关闭面板后保留「雨课堂助手」悬浮按钮，一键展开；关闭只影响当前页面，导航后恢复。
- 手机竖屏使用自适应宽度、受限高度、内部滚动和触控按钮，避免横向溢出。桌面支持拖动并限制在可视范围，旋转屏幕或改变窗口大小时恢复可见位置。
- 下载与答题分为两个页签，保留已有课件采集、并发下载、保存确认及失败重试功能。

| 答题模式 | 行为 |
| --- | --- |
| 随机选择并自动提交 | 从网站实际选项中随机选答案，等待所设延迟再提交；若临近截止，提前提交。多选随机选取非空子集。无需 API。 |
| AI 回答后自动提交 | 有效回答返回后立即提交；AI 超时、网络/接口错误、无效答案或即将截止时随机兜底。不会在成功后再次兜底。 |
| AI 仅显示回答 | 在面板中显示选项和理由，需自己在网页上作答。超时或错误也绝不随机提交。 |

AI 模式必须填写 **API Key、Base URL、模型名称**，调用 compatible `/chat/completions`，支持填写基础地址或完整接口地址。预设硅基流动、阿里云百炼（北京）、DeepSeek 端点；模型 ID 由用户根据账户权限填写。阿里云不同地域/工作空间应使用其控制台给出的地址。端点核对来源：[硅基流动](https://docs.siliconflow.cn/docs/api/chat-completions-post)、[百炼](https://help.aliyun.com/zh/model-studio/model-calling-in-sub-workspace)、[DeepSeek](https://api-docs.deepseek.com/)。

默认同时发送题目图片，模型必须支持视觉输入；也可以取消图片，仅发送题干和选项。图中公式或图形可能没有对应文字，此时应保留图片。图片先下载为内嵌数据，提供商不会收到课程图片签名 URL、课堂 Cookie 或课堂认证头。密钥保存在 Tampermonkey 的脚本存储中（非加密保险库），不写入网站 localStorage、日志或 iframe 通信；界面只显示保存状态，更换端点需重新填写密钥。「清除密钥」会同时停用答题。

默认随机延迟 3 秒、AI 总等待 20 秒、截止前兜底 3 秒；AI 等待包含图片读取。仅显示模式不使用截止兜底。点击「立即停用」、手动作答、老师结束题目或连接关闭会取消等待中的自动操作；已经发出的提交无法撤回。设置在支持 `GM_addValueChangeListener` 的脚本管理器中同步到其他标签页。

答题读取课件中的 `problem` 数据及课堂 WebSocket 发题、计时消息，不通过图片文件名猜题，也不批量回答历史课件。提交复用题目所在 iframe 的网页请求客户端，以保持其登录与 CSRF 上下文。只有接口返回 `code: 0` 才显示成功；结果不明或失败时不自动重试，需检查原网页。浏览器支持 Web Locks 时跨标签页串行登记提交，同一题的防重复记录保留 24 小时。不支持 Web Locks 时请仅在一个课堂标签页开启答题。

脚本尽早监听新连接，并尝试从当前 Vue 2 课堂组件恢复已有连接和正在显示的题目；如果面板始终未识别题目，刷新外层课堂页重新建立连接。手机后台冻结、断网、脚本管理器未授权跨域请求可能使倒计时任务无法及时运行；恢复后不会补交已过期的题目。关闭网页后不运行答题。

协议分析与验证记录见 [docs/1.2.0-analysis.md](docs/1.2.0-analysis.md)。本地测试不连接真实课堂或付费 AI 服务。

> 本项目使用Deepseek-V4 Pro模型基于 [RainClassroom_Download](https://github.com/c0d805e15c550432/RainClassroom_Download) 重构而来，并进行了功能增强。

## 🎯 功能特性

- **课件 PPT 下载**：自动拦截雨课堂课件接口，多个课件任务并发执行，图片使用共享连接池下载并按页码合成为 PDF
- **录播视频下载**：自动拦截视频回放 URL，支持 HTTP Range 分段并发下载 `.mp4`，校验每段范围、长度和最终文件大小
- **手动确认模式**：所有捕获到的课件和视频会展示在面板中，由用户手动勾选后统一下载，避免误下载
- **每个标签页一个面板**：内嵌 iframe 只采集资源，由顶层页面统一显示可拖拽、最小化、关闭的面板及并发任务进度；登录页和二维码登录弹层自动隐藏面板
- **会话持久化**：刷新页面或关闭标签页后，未下载的列表项仍可恢复
- **独立勾选状态**：资源列表跨标签页共享，勾选状态保存在各标签页的 sessionStorage 中，其他页面同步资源时不会覆盖当前选择
- **失败可重试**：下载失败的项目会回到待选列表；图片缺页时不会静默输出不完整 PDF
- **保存结果确认**：资源并发下载，导出依次进行；只有收到保存成功回调才计入“已保存”，保存失败保留文件供直接重试或另存为
- **中文操作界面**：面板、按钮、脚本菜单、状态、日志及新文件名前缀使用中文
- **智能命名**：自动根据课程名称、教师姓名、课件编号生成下载文件名

### 1. 安装用户脚本管理器

首先在浏览器中安装 Tampermonkey 扩展：

- [Chrome 版](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)
- [Edge 版](https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd)
- [Firefox 版](https://addons.mozilla.org/firefox/addon/tampermonkey/)

### 2. 安装脚本

在 Tampermonkey 中新建一个用户脚本，将 `main.js` 的全部内容复制粘贴进去并保存。

或者直接在 Tampermonkey 中导入 `main.js` 文件。

**Edge + Tampermonkey 保存设置：** 在 Tampermonkey 控制面板的设置中，将下载模式设为 **浏览器 API（Browser API）**，按扩展提示授予下载权限，并允许 `pdf`、`mp4` 文件扩展名。脚本通过 [`GM_download`](https://www.tampermonkey.net/documentation.php?locale=en&q=GM_download) 的成功/失败回调确认保存，不再使用无法判断结果的自动点击链接。请在开始下载前完成设置；若文件已进入“待保存”区，可直接使用“另存为”，不要为更新设置而先刷新页面。

### 3. 使用

1. 打开 [雨课堂网页版](https://pro.yuketang.cn/) 并登录
2. 进入任意课程，浏览课件或观看录播视频
3. 非登录页面右下角会自动出现 **雨课堂助手 1.2.0**；关闭后可点击悬浮按钮重新展开，也可使用脚本菜单 **显示 / 隐藏面板**
4. 当你浏览课件或播放视频时，脚本会自动捕获对应的资源并添加到面板列表中
5. 在面板中勾选需要下载的项目，点击 **「下载选中」** 按钮
6. 课件生成 PDF，视频生成 MP4，然后依次导出；以“已保存”计数和浏览器下载记录确认结果
7. 若出现“待保存文件”，按该条目的中文提示处理权限后点击 **重试保存**，或点击 **另存为…** 选择保存位置，无需再次下载资源

## 📖 使用说明

### 面板介绍

| 区域 | 说明 |
|------|------|
| 统计栏 | 显示待下载、已选、待保存和已保存数量；已保存累计数跨标签页共享，待保存文件仅在当前标签页 |
| 当前任务 | 显示正在下载的任务名称和进度 |
| 课件采集状态 | 区分等待接口、已加入课件、已有记录跳过、解析不到课件页和请求失败；面板创建前的日志也会保留 |
| 待确认列表 | 所有捕获到的课件和视频，支持勾选和移除 |
| 操作按钮 | 全选 / 取消全选 / 下载选中 / 清空列表 |
| 待保存文件 | 显示排队保存、正在保存或保存失败的文件，提供重试保存和另存为 |
| 日志区 | 实时显示捕获、下载、错误等运行日志 |

### 操作按钮

| 按钮 | 功能 |
|------|------|
| **全选** | 勾选列表中所有项目 |
| **取消全选** | 取消所有勾选 |
| **下载选中** | 默认最多同时下载 3 个任务；入队后从待选列表移除，网络下载失败时重新出现且不勾选，导出失败时保留在待保存区 |
| **清空列表** | 只清空待下载项目，不丢弃已经生成的待保存文件 |
| **重新采集课件** | 恢复被旧采集记录过滤的课件，不清空视频、勾选状态和已保存计数；列表中、下载中和待保存的课件不会重复加入 |
| **重试保存** | 使用缓存中的完整文件再次请求 Tampermonkey 保存，不重新请求课程资源 |
| **另存为…** | 在支持此功能的浏览器中手动选择文件位置，写入并关闭文件成功后才计入已保存；取消或写入失败仍保留缓存 |

“另存为”使用浏览器的 [文件保存选择器](https://developer.mozilla.org/en-US/docs/Web/API/Window/showSaveFilePicker)，需要手动点击触发。自动保存同名文件采用自动改名，避免覆盖已有文件；另存为时如选择已有文件，请留意浏览器的覆盖确认。

**待保存文件只缓存在当前页面内存中。请先完成导出，再刷新或关闭标签页。** 脚本会在离开时尝试触发浏览器提醒，但不能防止崩溃、强制关闭或浏览器回收页面。保存超时时会保留文件，不自动重试，以免重复导出；请先检查浏览器下载列表，再决定是否重试。关闭面板、清空列表或清除采集记录都不会丢弃待保存文件。

### 命名规则

- **课件 PDF**：`[课件] 课程名称_教师姓名.pdf`（多个课件会追加序号 `_1`, `_2`, `_3` ...）
- **录播视频**：`[录播] 课程名称_教师姓名.mp4`


## ⚙️ 配置说明

在脚本开头的 `CONFIG` 对象中可以调整以下参数：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `MAX_WORKERS` | 12 | 当前标签页图片和视频分段请求共用的最大连接数 |
| `MAX_CONCURRENT_JOBS` | 3 | 同时执行的课件/视频任务数，也用于课件信息获取的并发上限 |
| `VIDEO_WORKERS` | 4 | 单个视频的分段请求并发数，仍受 `MAX_WORKERS` 限制 |
| `VIDEO_CHUNK_BYTES` | 8388608 | 每个视频分段的字节数，默认 8 MiB |
| `MAX_RETRIES` | 3 | 图片/视频请求暂时失败后的额外重试次数；404 等永久错误不重试 |
| `RETRY_BACKOFF_MS` | 800 | 重试退避基础间隔（毫秒） |
| `VIDEO_TIMEOUT_MS` | 600000 | 视频下载超时时间（默认 10 分钟） |
| `SAVE_TIMEOUT_MS` | 600000 | 每次自动导出等待保存确认的超时（默认 10 分钟）；超时中止该次导出并保留文件 |

并发参数应为正整数，`MAX_RETRIES` 可为 0。视频会先请求首段验证服务器能力；服务器直接返回完整文件时复用该响应，不重复下载。后续分段失败或返回范围不一致时会取消其余分段并回退到单连接下载。[HTTP Range 工作方式](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Range_requests)

并发指多个网络请求同时进行，PDF 合成仍在浏览器主线程执行。实际速度受服务器限速、网络带宽和浏览器限制影响，不能保证固定提速倍数。视频仍需在浏览器中缓存完整文件，大视频或低内存设备建议降低任务并发数。网络任务不等待文件保存队列，因此导出排队不会占用下载工作槽。“已保存”表示收到 Tampermonkey 成功回调，或另存为写入并关闭成功；后续人为删除或移动文件不会反向更新此统计。

顶层页面必须匹配 `https://pro.yuketang.cn/*`；脚本不会在外站内嵌的雨课堂页面中单独弹出面板。不要加 `@noframes`，否则会漏掉 iframe 中的接口。资源状态写入使用 [Web Locks](https://developer.mozilla.org/en-US/docs/Web/API/Web_Locks_API) 协调多个标签页；不支持该 API 的旧浏览器只能保证当前标签页内串行修改。正在下载的任务不支持关闭/刷新标签页后续传。

### 升级与验证

将更新后的 `main.js` **完整覆盖**到原用户脚本中保存，包括头部的 `@grant unsafeWindow`、`@grant GM_download` 和 `@grant GM_info`。完成保存设置后，刷新雨课堂外层标签页加载新版本；若当前已有待保存文件，请先导出。不要同时启用两个版本。旧版待选列表会自动读取，英文课件/录播前缀转换为中文。

**1.1.3 课件采集补全：** 保留 1.1.2 的保存队列与中文界面，补上 `/classroom-report/student/ppt` 和 `/classroom-report/ppt` 直接课件响应。iframe 汇总时保留查询参数中的课程和课件编号，使直接响应能与课程信息的后续请求去重。原来的 `lesson-info → 请求课件` 流程继续保留；即使后续补请求失败，页面实际获取到的课件响应仍可独立进入列表。

如果课件列表为空，先确认面板标题显示 **1.2.0**，打开课件后查看 **课件采集** 状态。提示被已有记录跳过时，点击 **重新采集课件**。它优先重用当前页面实际捕获的响应，也可回放浏览器记录中的课件读取接口，仅恢复待下载列表，不自动下载。恢复最多检查最近 20 个不同的课件接口记录，可能包含本标签页稍早浏览的课程；请按需勾选。列表中或当前标签页正在下载、等待保存的项目不会重复添加。如果始终显示等待接口或请求失败，请保留运行日志并重新进入课件页面。

课件接口也增加了资源记录兜底：当网站缓存或替换了 fetch/XHR 导致拦截遗漏时，补读实际观察到的已知读取接口；已由正常拦截处理的响应不会重复请求。同一接口下的不同课件分别补采，不再只保留最后一个。上述路径已有针对性模拟回归验证，仍需实际 Edge + Tampermonkey 课程会话确认，不能仅凭本地测试判定用户遇到的问题只有这一个原因。

**1.1.2 导出修复与中文界面：** 修复三个任务都显示完成但只有一个文件保存的问题。旧逻辑直接点击下载链接并立即累计完成数；新版本等待保存结果、顺序导出、保留失败文件并支持另存为。旧版未经确认的完成计数会重置，不影响磁盘中已有文件。旧版当时未保存的文件无法从新脚本中恢复，需在菜单中选择 **清除采集记录（允许重新采集）**，再重新扫描或进入相应课程，只勾选缺失文件重新下载。

**1.1.1 采集回归修复：** 1.1.0 在用户脚本沙箱中可能将页面窗口与沙箱窗口混淆，导致 iframe 采集结果被丢弃，表现为面板不自动打开且列表一直为空。当前版本通过 [`unsafeWindow`](https://www.tampermonkey.net/documentation.php?locale=en&q=unsafeWindow) 拦截页面实际使用的 fetch/XHR/媒体对象，并通过同源顶层文档上的字符串 DOM 事件汇总 iframe 数据，不再依赖 `postMessage.source` 与沙箱窗口相等。

同时恢复识别 `/classroom-report/lesson-info` 和 `/classroom-report/student/lesson-info` 两种接口及尾部斜杠。脚本加载较晚时，会补扫已有视频及浏览器资源记录中保留的课件读取接口；可在 Tampermonkey 菜单中点击 **重新扫描当前页面** 手动重扫所有同源内嵌页。普通扫描保留已有去重规则；需要恢复被过滤的课件时使用 **重新采集课件**。如果当前页面既没有已捕获响应，也没有浏览器请求记录，需重新进入课件页面；脚本不会猜测课程 ID。
