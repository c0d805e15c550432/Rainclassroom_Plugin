# 1.2.0 实现与验证记录

## HAR 中实际发生的答题流程

分析文件为项目内 `example/firebaseinstallations.googleapis.com_2026_09_14_.har`。这是实际磁盘文件名；请求按 `_id` 对应用户给出的编号，不按数组下标。未连接、重放或提交其中的真实账号请求，未将 Cookie、Authorization、WebSocket 握手令牌写入本报告或测试。

| 请求编号 | 内容 | 结论 |
| --- | --- | --- |
| 572、578、669 | POST `/api/v3/lesson/problem/answer` | 三次提交均返回 `code: 0`，参数含字符串 `problemId`、数字 `problemType`、当前毫秒时间戳 `dt`、选项 key 数组 `result` |
| 568、575、667 | 题目 JPG 图片 | 对应课件页的 cover，不能单凭图片请求判断是否发题、是否可提交或截止时间 |
| 571、574、668 | POST `/video-log/log/track/` | 页面访问统计 `page_view`，不作为题目或计时依据 |
| 354、374、474、679 | GET `/api/v3/lesson/presentation/fetch` | `data.slides[].problem` 提供题目 ID、题型、题干、选项及已有结果；同一页的 cover 对应题图 |
| 351、677 | `/wsapp/` 的 WebSocket 连接 | 课堂消息提供发题与时间；HAR 使用 `_webSocketMessages[].payload.text`，`flow: 1` 为接收方向 |

三道示例题的 problem ID 分别以 1010、1011、1019 结尾，对应第 19、20、28 页，均为 `problemType: 1`、A/B 两选项。`result` 为 `["B"]`，而不是选项文字或数组序号。大整数 ID 必须保留字符串，不能转为 JavaScript Number。

发题链路是 `unlockproblem → problem.prob → slides[].problem.problemId`。`probleminfo` 中 `dt` 为发题时间，`now` 为服务器当前毫秒时间，`limit` 为秒；三道示例均为 `-1`（不限时）。不能把课件静态字段 `sendTime: 0 / limit: 0` 当成实际开题状态。老师未发题的课件不进入答题任务。

HAR 自带的网页脚本（请求 570）确认了题型 1 为单选、2 为多选，以及 `window.request.post(API.lesson.answer_problem, payload)` 的提交流程；课堂脚本（340、337）确认 `problemfinished`、`extendtime` 的结束/续时处理及 `limit - floor((now - dt) / 1000)` 的剩余时间计算。续时和倒计时逻辑有本地模拟覆盖，但这份 HAR 的三次实际作答均不限时，不能声称它验证了真实限时题。

## 实现取舍

- 面板只在顶层创建。修复旧版“仅指定路由或捕获资源后才显示”的限制；保持登录页/二维码弹层隐藏，避免恢复 iframe 重复窗口问题。
- 单文件用户脚本，不增加用户安装构建依赖。GUI 分为下载与答题两个页签，保留已有下载状态和队列。
- 每个同源 iframe 拦截自己的课件响应和课堂连接，只向顶层传递题目数据、时间及状态；顶层统一调度 AI 与计时。提交回到持有题目的 iframe，复用网页现有请求客户端，不复制 HAR 凭据。
- `hello` 的完整时间轴不批量触发历史题，只尝试恢复当前显示且已解锁的题。脚本启动较晚时，尝试挂接现有 Vue 2 组件的连接并恢复当前习题；页面结构不匹配时保留刷新课堂页的回退路径。
- 发题先于课件响应时暂存激活信息，课件到达后补齐；重复消息不重新开始延迟。AI 请求时间从任务启动计算，包含图片读取。
- 先同步标记提交尝试，再异步领取跨标签页记录；提交前再次检查开关、模式版本、已答状态、结束状态和截止时间，避免 AI/倒计时竞争及设置切换后的误交。
- 网络/响应不确定时不自动重试写操作。仅 `code: 0` 计为成功。随机兜底只适用于自动模式；仅显示模式没有任何自动提交分支。
- AI 按选项 key 校验结构化回答，拒绝无效选项、单选返回多个选项、重复选项以及从长段文字中猜字母。AI 理由用 `textContent` 展示，不解释为 HTML。
- GM 请求使用独立认证头、`anonymous: true`；图片先转为内嵌数据。AI Key 只保存在脚本管理器，防重复记录只含课堂/题目 ID 与时间。更换端点必须重新输入密钥。

## 验证

自动测试命令（Node.js 18+，无需安装依赖）：

```powershell
node --check main.js
node --test tests/downloader.test.cjs tests/quiz.test.cjs
```

共 80 项测试全部通过（原有 52 项下载回归 + 新增 28 项答题测试）。新增答题测试覆盖默认关闭、未发布题、晚到课件、重复消息、三种模式、AI 格式/网络错误、计时兜底、时钟偏差、续时、手动作答、关闭、模式切换、iframe 原页面提交、跨标签页防重复及后台唤醒后的过期检查。

本地浏览器夹具新增「发布模拟选择题」「结束模拟题」和模拟 Compatible API。AI 测试使用虚构密钥，取消发送图片即可返回本地模拟答案。所有题目、请求和提交均为模拟，不调用真实课堂服务。

真实浏览器检查：默认自动显示；两层 iframe 面板计数为 `1, 0, 0`；随机模式能通过模拟网页客户端提交并确认成功；AI 仅显示模式显示建议；关闭后悬浮按钮可恢复面板。竖屏按 390×844、320×640 检查并修复滚动条导致的宽度溢出；登录路由隐藏面板和悬浮按钮，返回课程路由后自动恢复。

## 仍需实站确认的边界

未在用户登录中的课堂提交真实答案，也未调用收费 AI 模型。实际移动端脚本管理器的跨域授权、`unsafeWindow`/WebSocket 挂接兼容性、页面请求客户端、后台冻结行为和真实题目的最终保存结果，需要安装更新后在实站验证。

当前支持同源 `pro.yuketang.cn` 嵌套网页中的课堂选择题；填空、主观题、试卷、投票和跨域嵌入不自动作答。无 Web Locks 的浏览器不保证多个标签页同时争抢时的原子去重，应只开一个答题标签页。浏览器后台休眠后不补交已过期题。关闭助手面板不会停用答题；需要停止时使用「立即停用」。
